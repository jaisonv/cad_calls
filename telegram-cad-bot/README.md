# Telegram CAD Calls Monitor Bot

Go binary used by the Docker deployment for CAD call monitoring.

## Build

Build a Linux binary (required for deployment):

```bash
CGO_ENABLED=1 GOOS=linux GOARCH=amd64 go build -o cadbot ./cmd/bot
```

Use `GOARCH=arm64` for ARM servers.

## Docker Deployment

Use the canonical deploy bundle in the parent repo:

- `../deploy/docker/docker-compose.yml`
- `../deploy/docker/setup.sh`
- `../deploy/docker/.env.example`

Full instructions:

- `../INSTALL.md`
- `../deploy/docker/README.md`

## Runtime Notes

- The bot reads CAD settings from `cad_calls/config.py` generated by `setup.sh`
- The bot itself requires `TELEGRAM_BOT_TOKEN` and `CHECK_INTERVAL`
- SQLite state is persisted in `/data/cadbot.db`
